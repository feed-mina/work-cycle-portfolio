# 바탕화면 상단 배너

업무 3원칙을 하루 종일 화면 맨 위에 띄워둡니다.
앱 안의 3원칙 배너(`public/principles.js`)와 같은 취지를, PC 전체로 넓힌 것입니다.

```
▐ **업무 3원칙**  **고객 니즈 파악** — …  **AI 과신 지양** — …  **검증과 테스트 습관화** — … ▌
```

글자는 오른쪽에서 왼쪽으로 흐르고, 깜빡입니다. 문구는 work-cycle 사이트의 설정 창에서 바꿉니다.

---

## 최초 1회 설치

처음 한 번만 사이트와 PC 배너를 연결합니다.

1. work-cycle 화면 오른쪽 상단의 **상단 고정 배너** 버튼을 누릅니다.
2. 열린 설정 창에서 **최초 1회 설치**를 누릅니다.
3. 내려받은 `work-cycle-desktop-banner.pyw`를 더블클릭합니다.
4. 설치 완료 안내가 뜨면 사이트로 돌아옵니다.
5. 문구를 적고 **저장하고 배너 켜기**를 누릅니다.

설치 파일은 배너를 `%LOCALAPPDATA%\WorkCycleBanner`에 보관하고
`workcycle-banner://` 연결을 현재 Windows 사용자에게 등록합니다. 관리자 권한은 필요하지 않습니다.
컴퓨터를 껐다 켠 뒤에도 다시 설치할 필요 없이 사이트 버튼으로 실행할 수 있습니다.
처음 실행할 때 Chrome이 외부 앱을 열어도 되는지 한 번 물을 수 있습니다.

> Python이 설치되어 있어야 합니다. PowerShell에서 `python --version`을 실행해
> 버전이 나오지 않으면 Python을 설치하고 **Add python.exe to PATH**를 선택하세요.

---

## 사이트에서 쓰는 법 (권장)

오른쪽 상단 **상단 고정 배너**를 누르면 설정 창이 열립니다.

| 버튼 | 결과 |
|---|---|
| **문구만 저장** | 이 브라우저에 문구만 저장합니다. 배너는 실행하지 않습니다. |
| **저장하고 배너 켜기** | 문구를 저장하고 배너를 실행합니다. 이미 실행 중이면 잠시 후 새 문구로 바뀝니다. |
| **기본 문구로** | 입력란을 기본 업무 3원칙 문구로 되돌립니다. 저장은 별도로 눌러야 합니다. |

문구를 바꿀 때는 재설치나 재등록이 필요하지 않습니다.

## 개발 폴더에서 직접 쓰기

**`banner.pyw` 를 더블클릭하면 끝입니다.**

`.pyw` 확장자라 검은 콘솔 창 없이 배너만 뜹니다. exe로 만들 필요가 없습니다.

| 동작 | 결과 |
|---|---|
| 왼쪽 **⋮ 구역에서 우클릭** | 종료 — 가장 확실한 방법 |
| **Esc** | 종료. 단 배너가 키보드 포커스를 가진 동안만 먹습니다 (다른 창을 클릭하면 안 됨) |
| 배너 위에 **마우스 올리기** | 10% 농도로 흐려지고 클릭·드래그가 아래 창으로 통과함 |
| 왼쪽 **⋮ 구역에서 휠 클릭** | 10초 숨김 |

우클릭도 Esc도 안 들으면 작업 관리자(`Ctrl+Shift+Esc`)에서 `pythonw.exe` 를 끝내세요.

> Python 이 설치돼 있어야 합니다. PowerShell 에서 `python --version` 을 쳐서
> 버전이 나오면 준비된 것입니다. 안 나오면 python.org 에서 설치하고
> 설치 화면의 **"Add python.exe to PATH"** 를 체크하세요.

## 자동 시작에 넣기 (선택)

사이트 버튼을 누를 때만 실행하는 경우 이 설정은 필요 없습니다. Windows 로그인과 동시에
띄우고 싶을 때만 설치 후 `%LOCALAPPDATA%\WorkCycleBanner\banner.pyw`의 바로가기를 넣습니다.

1. `Win + R` → `shell:startup` → 엔터 (시작프로그램 폴더가 열립니다)
2. 설치된 `banner.pyw` 우클릭 → **바로가기 만들기**
   - 윈도우 11은 우클릭 메뉴가 짧습니다. **추가 옵션 표시**를 눌러야 보입니다
3. 생긴 바로가기를 잘라내 1번 폴더에 붙여넣습니다

> 두 폴더를 나란히 놓고 `Ctrl + Shift` 를 누른 채 끌어다 놓으면 2~3번을 한 번에 합니다.

**자동 시작을 끄려면** 같은 폴더(`shell:startup`)에서 바로가기를 지웁니다.
원본은 남아 있어 더블클릭하면 언제든 다시 뜹니다.

## 문구 바꾸기

사이트의 **상단 고정 배너** 설정 창에서 바꿉니다. 메모장을 열 필요가 없으며,
문구를 바꿔도 설치를 다시 하지 않습니다. 배너가 켜져 있으면 **저장하고 배너 켜기**를
누른 뒤 잠시 후 새 문구가 반영됩니다.

사이트를 쓸 수 없는 경우에만 `%LOCALAPPDATA%\WorkCycleBanner\banner.txt`를 UTF-8로
직접 수정할 수 있습니다.

## 움직임·깜빡임 조절

`banner.pyw` 맨 위 **설정** 구역에서 바꿉니다.

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `SCROLL` | `True` | 글자가 오른쪽 → 왼쪽으로 흐름. `False` 면 가운데 고정 |
| `SCROLL_SPEED_PX` | `2` | 한 번에 움직이는 픽셀. 크면 빠름 |
| `SCROLL_INTERVAL_MS` | `80` | 다시 그리는 간격. 작을수록 부드럽고 CPU를 더 씀 |
| `SCROLL_GAP_PX` | `120` | 문구가 한 바퀴 돌 때 사이 여백 |
| `BLINK` | `True` | 깜빡임 |
| `BLINK_INTERVAL_MS` | `700` | 깜빡이는 주기 |
| `COLOR_OFF` | `#7A6200` | 어두울 때 색. `"black"` 으로 하면 완전히 사라졌다 나타남 |
| `NORMAL_ALPHA` | `1.0` | 평소 배너 투명도. `1.0`이면 완전히 불투명 |
| `HOVER_ALPHA` | `0.10` | 마우스를 올렸을 때 투명도. `0.0`이면 안 보이고 `1.0`이면 변화 없음 |
| `HOVER_POLL_INTERVAL_MS` | `40` | 클릭 통과 중 마우스 위치를 확인하는 간격 |
| `CONTROL_ZONE_PX` | `28` | 왼쪽 ⋮ 조작 구역의 폭 |

**깜빡임은 완전히 끄지 않고 어둡게만 합니다.** 글자가 사라지지 않아 읽던 중에
끊기지 않고, 눈도 덜 피로합니다. 완전한 점멸을 원하면 `COLOR_OFF` 를 `"black"` 으로.

**흐를 때는 글자 크기를 줄이지 않습니다.** 흐르는 것 자체가 긴 문구를 다 보여주므로
축소가 필요 없습니다. `SCROLL = False` 로 두면 폭에 맞춰 자동으로 줄입니다.

### CPU

흐르게 하면 80ms마다 화면을 다시 그립니다(초당 12번). 캔버스 글자 두 개를
옆으로 미는 것뿐이라 부담은 작지만, **안 움직일 때보다는 확실히 많이 씁니다**.
노트북 배터리를 아끼려고 기본값을 `80` 으로 두었습니다. 더 매끄럽게 흐르길
원하면 `40` (초당 25번)으로 낮추세요 — 대신 CPU를 두 배로 씁니다.

## exe 로 만들고 싶다면

`build-exe.bat` 를 더블클릭하면 Python 확인 → pyinstaller 설치 → 빌드까지 한 번에 합니다.
결과는 `dist\work-cycle-banner\work-cycle-banner.exe`.

`--onefile` 이 아니라 **`--onedir`** 를 씁니다. onefile 은 실행할 때마다 임시폴더에
압축을 풀어 시작이 1~3초 느리고, 백신 오탐이 잦습니다.

> 서명 안 된 개인 exe 라 처음 실행 때 SmartScreen 경고가 뜰 수 있습니다.
> `추가 정보` → `실행` 으로 넘기세요.

**대부분의 경우 exe 는 필요 없습니다.** `.pyw` 더블클릭이 더 빠르고 문제도 적습니다.

## 동작 메모

코드에 들어 있는 처리와 이유입니다.

| 처리 | 이유 |
|---|---|
| `SetProcessDpiAwareness` | 안 켜면 화면 배율(125%·150%)에서 폭이 어긋나 오른쪽 끝까지 안 닿음 |
| 중복 실행 차단 (뮤텍스) | 두 번 켜면 같은 자리에 겹쳐 떠서, 우클릭해도 안 꺼지는 것처럼 보임 |
| Esc 종료 | `overrideredirect` 창은 작업표시줄에 안 뜸. 우클릭이 안 먹으면 작업관리자밖에 안 남음 |
| hover 클릭 통과 | `WS_EX_TRANSPARENT`로 아래 창의 탭·버튼·제목줄을 직접 조작 |
| 왼쪽 ⋮ 조작 구역 | 클릭 통과 상태에서도 배너 종료·숨김 동작을 유지 |
| 글자 크기 자동 축소 | 문구가 화면보다 길면 양끝이 잘려 아무 말도 안 보이게 됨 |
| 30초마다 topmost 재설정 | 전체화면 앱이 뜨면 맨 위 자리를 뺏기는 경우가 있음 |
| 흐를 때 문구를 **둘** 그림 | 하나만 쓰면 문구가 완전히 빠져나간 뒤 다시 들어올 때까지 화면이 비어 끊겨 보임 |

**30초 간격을 더 짧게 하지 마세요.** 전체화면 영상·게임을 쓸 때 그 주기마다
화면이 깜빡이거나 전체화면이 풀릴 수 있습니다. CPU 부담 때문이 아니라
(하루 종일 돌아도 CPU 1초 미만) 방해가 되기 때문입니다.
바꾸려면 `banner.pyw` 의 `TOPMOST_INTERVAL_MS` 를 고치세요.

## 알아둘 제약

- 평소에는 배너가 **모든 창의 맨 위 45px 위에 표시**됩니다. 마우스를 올리면 흐려지고,
  아래 창의 탭·닫기 버튼·제목줄을 클릭하거나 드래그할 수 있습니다.
- 왼쪽 28px의 **⋮ 조작 구역**만 클릭을 통과시키지 않습니다. 배너를 종료하거나
  10초 숨기려면 이 구역에서 우클릭하거나 휠 클릭하세요.
- 주 모니터 맨 위에만 뜹니다. 다중 모니터 중 보조 화면에는 안 뜹니다.
- Windows 전용입니다 (DPI·뮤텍스 처리가 Windows API).
