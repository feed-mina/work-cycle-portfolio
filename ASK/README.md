# ASK 로그 관리

Claude와 Codex에게 한 질문과 답변을 하루 단위로 요약해 보관하는 폴더입니다.

## 파일 이름

```text
YYYY-MM-DD_ai.md
```

## 기록 대상

- Claude와 나눈 질문·응답
- Codex와 나눈 질문·응답
- 두 도구가 같은 주제에서 이어서 작업한 내용

## 작성 규칙

질문마다 한 블록으로 기록합니다.

```markdown
## 주제 요약
**도구:** Claude 또는 Codex 또는 Claude+Codex
**질문:** 한 줄 요약
**응답 요약:**
- 핵심 응답 1
- 핵심 응답 2
- 필요하면 다음 할 일
```

파일이 없으면 이 헤더로 시작합니다:

```markdown
# YYYY-MM-DD Claude/Codex 질문·응답 로그

> 작성 규칙: 질문마다 한 블록. 질문 한 줄 요약 + 응답 2~3줄 요약.
> 도구 구분: `Claude`, `Codex`, 또는 `Claude+Codex`.

---
```

## 원칙

- **git 근거만**: 오늘 커밋·작업트리·아티팩트에 근거해서만 기록. 추측·창작 금지.
- **보존(append)**: 기존 내용을 훼손하지 말고 새 블록만 덧붙입니다.
- 자동 기록을 잠시 멈추려면 저장소 루트에 `.ask_paused` 파일을 둡니다(삭제하면 재개).
